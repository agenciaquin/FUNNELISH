# Paquete de replicación — QuinChat (embudos) idéntico en otra app

Con esto dejas el sistema **igualito** en otro proyecto. Tres partes:
**A) copiar el código**, **B) crear la base de datos (SQL)**, **C) variables de entorno**.

---

## A) Copiar el código

El código vive en el repo `github.com/agenciaquin/FUNNELISH`, carpeta **`quinchat`**.
Para la otra app, la forma más fiable:

1. Copia toda la carpeta `quinchat/` al nuevo proyecto (o crea un proyecto en Vercel que
   apunte a ese mismo código / a un fork del repo).
2. Instala dependencias: `npm install`.
3. Configura las variables de entorno (parte C) en `.env.local` y en Vercel.
4. Corre la base de datos (parte B) en el nuevo Supabase.
5. `npx tsc --noEmit` y `vercel --prod`.

> No basta con un MD de descripción: para que quede idéntico hay que copiar los archivos
> reales (componentes, endpoints, lib) + base + env + integraciones.

---

## B) Base de datos (Supabase) — SQL completo

Pega esto en **Supabase → SQL Editor → Run** del nuevo proyecto. Es idempotente.

```sql
-- ── EMBUDOS ─────────────────────────────────────────────────────────────────
create table if not exists funnels (
  id uuid primary key default gen_random_uuid(),
  slug text not null unique,
  activo boolean default true,
  nombre text, titulo text, producto text,
  precio numeric, precio_antes numeric,
  imagenes jsonb default '[]'::jsonb,
  imagen_banner text, imagen_clientes text, imagen_detalle text,
  caracteristicas jsonb default '[]'::jsonb,
  tallas jsonb default '[]'::jsonb,
  variantes jsonb default '[]'::jsonb,
  frases jsonb default '[]'::jsonb,
  horas_contador integer default 10,
  personas_comprando integer default 27,
  whatsapp text,
  pixel_meta text, pixel_meta_token text,
  pixel_tiktok text, pixel_tiktok_token text,
  audio_url text, video_url text, color text, miniatura_url text, anuncios text,
  layout jsonb,
  insignia jsonb,
  eliminado boolean not null default false,
  eliminado_at timestamptz,
  creado_at timestamptz default now()
);
create index if not exists idx_funnels_activo on funnels(activo) where eliminado = false;

-- ── PEDIDOS ─────────────────────────────────────────────────────────────────
create table if not exists clientes_funnelish (
  id bigint generated by default as identity primary key,
  telefono text not null,
  nombre text, producto text, talla text, valor text,
  ciudad text, departamento text, direccion text, correo text,
  referencia text,
  wa_enviado boolean default false, wa_enviado_at timestamptz,
  confirmado boolean default false, confirmado_at timestamptz,
  estado text default 'pendiente',
  fecha_pedido date,
  cantidad integer not null default 1,
  foto_producto text,
  funnel_slug text,
  utm_source text, utm_medium text, utm_campaign text, referrer text,
  abono numeric default 0, abono_recibido boolean default false, abono_recibido_at timestamptz,
  registro_enviado boolean not null default false, registro_at timestamptz,
  contacto_at timestamptz, papelera_at timestamptz,
  remarketing_1_at timestamptz, remarketing_2_at timestamptz,
  preguntas_pendientes text, direccion_ok boolean default false, pidio_confirmar boolean default false,
  created_at timestamptz default now(),
  updated_at timestamptz default now()
);
create index if not exists idx_cf_telefono on clientes_funnelish(telefono);
create index if not exists idx_cf_referencia on clientes_funnelish(referencia);
create index if not exists idx_cf_funnel_slug on clientes_funnelish(funnel_slug);

-- ── CARRITOS ABANDONADOS ────────────────────────────────────────────────────
create table if not exists carritos_abandonados (
  id uuid primary key default gen_random_uuid(),
  slug text not null,
  telefono text not null,
  nombre text, producto text, talla text, valor numeric,
  datos jsonb, nota text,
  recuperado boolean not null default false, recuperado_at timestamptz,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);
create unique index if not exists uq_carrito_slug_tel on carritos_abandonados(slug, telefono);

-- ── RASTREO DEL EMBUDO ──────────────────────────────────────────────────────
create table if not exists funnel_eventos (
  id uuid primary key default gen_random_uuid(),
  slug text not null,
  paso text not null,           -- landing | scroll_fin | pedido | talla | datos | boton | compra
  utm_source text, utm_medium text, utm_campaign text, referrer text,
  created_at timestamptz not null default now()
);
create index if not exists idx_fe_slug_paso on funnel_eventos(slug, paso, created_at);

-- ── CATÁLOGOS (colores con foto) ────────────────────────────────────────────
create table if not exists catalogos (
  id uuid primary key default gen_random_uuid(),
  familia text, patron text, anuncios text,
  created_at timestamptz default now()
);
create table if not exists catalogo_colores (
  id uuid primary key default gen_random_uuid(),
  catalogo_id uuid references catalogos(id) on delete cascade,
  color text not null, nombre_producto text not null,
  url_imagen text, url_original text,
  variante jsonb default '{}'::jsonb,
  activo boolean default true, orden integer default 0,
  created_at timestamptz default now()
);

-- ── CHAT (WhatsApp) ─────────────────────────────────────────────────────────
create table if not exists conversations (
  id text primary key,               -- teléfono, ej. 573001234567
  contact_name text not null default '',
  last_message text not null default '',
  last_message_time timestamptz not null default now(),
  unread_count integer not null default 0,
  bot_enabled boolean not null default true,
  label text, status text default 'nuevo',
  origen_anuncio text, anuncio_origen text, anuncio_id text,
  fijado boolean default false, linea text,
  interaccion_bot boolean not null default false,
  entrega_fallida boolean not null default false,
  seguimiento_enviado boolean, seguimiento_at timestamptz, seguimiento_n integer not null default 0,
  vendido_at timestamptz, capi_enviado_at timestamptz, promo_cierre_at timestamptz,
  notas text,
  created_at timestamptz not null default now()
);
create table if not exists messages (
  id text primary key,
  conversation_id text not null,
  content text not null,
  role text not null,                -- user | assistant
  type text not null default 'text', -- text | image | ...
  whatsapp_id text, reply_to text, status text, error_envio text, caption text,
  created_at timestamptz not null default now()
);
create index if not exists idx_msg_conv on messages(conversation_id, created_at);

-- ── PERMISOS (MUY IMPORTANTE) ───────────────────────────────────────────────
-- El servidor usa la SERVICE ROLE KEY. Sin estos grants, da "permission denied".
grant all on all tables in schema public to service_role;
grant all on all sequences in schema public to service_role;
alter default privileges in schema public grant all on tables to service_role;
alter default privileges in schema public grant all on sequences to service_role;
```

> Si activas RLS, recuerda dar acceso al rol `authenticated` (panel) y dejar públicas
> las lecturas que necesita la página de venta, o hacer esas lecturas con service role.

**Storage de imágenes:** el proyecto sube fotos/videos a **Cloudflare R2** (o al Storage
de Supabase como respaldo). Crea el bucket R2, ponlo público y configura CORS
(PUT desde tu dominio). Las llaves van en las variables (parte C).

## C) Variables de entorno (checklist)

Ponlas en `.env.local` y en Vercel (Project → Settings → Environment Variables).

**Base de datos (Supabase)**
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`  ← servidor (crítica)
- `SUPABASE_JWT_SECRET`

**Login del panel**
- `NEXTAUTH_SECRET`

**WhatsApp Cloud API (Meta)**
- `WHATSAPP_ACCESS_TOKEN`
- `WHATSAPP_PHONE_NUMBER_ID` (y opcional `WHATSAPP_PHONE_NUMBER_ID_VENTAS`)
- `WHATSAPP_WABA_ID`, `WHATSAPP_APP_ID`
- `WHATSAPP_VERIFY_TOKEN` (para el webhook)
- `WHATSAPP_NUMERO_BOT` (el número que ve el cliente)

**Meta Ads / CAPI (Conversiones)**
- `META_ADS_TOKEN`, `META_AD_ACCOUNT_ID`
- `META_CAPI_DATASET_ID`, `META_COSTO_OBJETIVO`

**IA (bot / análisis)** — según lo que uses
- `ANTHROPIC_API_KEY`, `GROQ_API_KEY`, `QUINCHAT_MODEL`, `SEGUIMIENTO_IA`

**Cloudflare R2 (imágenes)**
- `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET`, `R2_PUBLIC_URL`

**Notificaciones push (PWA)**
- `NEXT_PUBLIC_VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`

**Crons y transportadora (opcionales)**
- `CRON_SECRET`
- `LUPAP_API_KEY`, `LUPAP_API_SECRET` (Effi/guías), `CONFIRMA_YA_API_KEY`

## D) Integraciones a conectar (fuera del código)

1. **Dominio**: apunta tu dominio (ej. `pedido.tudominio.com`) a Vercel. El middleware
   detecta el host `pedido.` para servir la tienda.
2. **WhatsApp Business API**: configura el webhook `/api/whatsapp/webhook` con tu
   `WHATSAPP_VERIFY_TOKEN`, y agrega las plantillas de mensajes (aprobadas en Meta).
3. **Pixel de Meta**: crea el pixel, pon su ID en cada embudo (`pixel_meta`) y el token
   de CAPI (`pixel_meta_token`). Verifica en Administrador de eventos.
4. **Cloudflare R2**: bucket público + CORS para subir imágenes.
