## 4. Privilegios por defecto (pg_default_acl) sobre `public`, tipo tabla

| Otorgado por | anon / authenticated reciben |
| --- | --- |
| `postgres` | `Dxtm` -> TRUNCATE, REFERENCES, TRIGGER, MAINTAIN. **Sin DML.** |
| `supabase_admin` | `arwdDxtm` -> **DML completo** |

El editor SQL del dashboard y las migraciones se ejecutan como `postgres`, asi
que **una tabla nueva creada por la via normal nace cerrada** — exactamente la
forma que ya funciona en `confirma-ya`. El REVOKE no se deshara solo con el
tiempo.

Queda la via de `supabase_admin`, que si abre DML por defecto. No es la que se
usa a mano, pero conviene saber que existe.
