# QUIN LIVE SHOPPING — Maqueta

- Panel: menú lateral → **QUIN LIVE SHOPPING** (enlace y botón "Abrir maqueta").
- Público (sin login): `/live/demo` (en `pedido.klixmant.shop/live/demo` una vez publicado).
- Local: `cd quinchat && npm run dev` → http://localhost:3000/live/demo
- Variables opcionales: `NEXT_PUBLIC_LIVE_VIDEO_URL` (R2), `NEXT_PUBLIC_LIVE_WHATSAPP` (ej. 573001234567), `NEXT_PUBLIC_LIVE_PRIVACIDAD_URL`.
- Medición de prueba: abre la consola del navegador y busca `[QUIN LIVE]`.
- Carpetas: `components/live/`, `lib/live/`, `app/live/`, `public/live-demo/`.
